# Objetivo
Garantir que o uso do dado tenha base legal e finalidade legítima.

# Checklist
- [ ] Definir finalidade (por que existe?).
- [ ] Definir base legal (ex.: obrigação legal/regulatória, execução contratual, legítimo interesse, consentimento).
- [ ] Minimização: só o necessário para o problema.
- [ ] Retenção: prazo + descarte seguro.
- [ ] Compartilhamento: quem recebe? por quê? controles?

# Saída
- Aprovar / Aprovar com ressalvas / Bloquear (com justificativa)

# Constraints
- Sem base legal clara → BLOQUEAR.
