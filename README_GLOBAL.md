# Finance Data Governance OS

AI Governance + Data Governance framework for financial institutions.

## Vision
Create audit-ready, compliant and production-safe AI/data environments for banks and regulated industries.

## Core pillars
- AI Governance
- Data Governance
- ML auditability
- Evidence-first pipelines
- LGPD/BACEN/CVM ready

## Why this exists
Financial institutions need safe AI adoption without regulatory risk.

This framework provides:
- governance workflows
- compliance automation
- model auditability
- secure data usage patterns
