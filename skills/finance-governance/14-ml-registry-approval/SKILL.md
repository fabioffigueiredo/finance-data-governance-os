# Objetivo
Governança de modelos: versionamento, aprovações e rastreabilidade.

# Checklist
- [ ] Model card (finalidade, dados, métricas, riscos).
- [ ] Aprovação (quem aprovou, quando, por quê).
- [ ] Requisitos para produção: testes, performance, segurança.
- [ ] Rollback planejado.

# Constraints
- Sem aprovação: não promover para produção.
