# Finance Data Governance OS

Este site documenta o **Finance Data Governance OS**, um kit de **Agents + Skills** para governança de dados e ML no mercado financeiro.

## O que você ganha
- Fluxo operacional para LGPD + controles de segurança e auditoria (Bacen/CVM)
- Treino de modelos com **dados sensíveis sem expor dataset bruto** (compute-to-data)
- Catálogo, lineage, contratos de qualidade e evidências (report + evidence.json)
- Guia de **storytelling e BI** para apresentar resultados com segurança

> **Importante:** use somente em ambientes autorizados. Nunca exporte dados brutos sensíveis.
